🍢 Satay Kajang Uncle Ujang Online Ordering System - Group G05_38
The Satay Kajang Uncle Ujang Online Ordering System is a dedicated online ordering platform built for the Final Year Project of the Software Development Course (DDWD3723) by group G05_38. 
This platform is designed to sell a diverse range of satay (chicken, beef, lamb, and others), along with complementary dishes such as nasi impit (compressed rice) and peanut sauce (kuah kacang). It allows customers to conveniently browse the menu and place their orders from anywhere.

The system features integrated Admin and Staff dashboards that enable monitoring of customer feedback, item stock levels, orders, user/staff credentials, and sales reports.

🛠️ Installation
To run this program in your local environment, you will need to install the following software:

XAMPP

⚙️ Installing XAMPP
Download the Windows Installer from the https://www.apachefriends.org/download.html .

<img width="1901" height="865" alt="xampp_page" src="https://github.com/user-attachments/assets/2e892440-34f3-4b12-8fa2-279ac116660d" />

Ensure you download a suitable version of XAMPP. A recent version usually includes:

Apache

MariaDB (or MySQL)

PHP

phpMyAdmin

And other standard XAMPP components.

Note: Use this video https://www.youtube.com/watch?v=yHkxKyNL2gE as a guideline on how to install and setup XAMPP wizard. It also shows how to open phpMyAdmin which will be used to store database for the project.

⛓️ Getting Started
Follow these steps to get the system up and running:

<img width="825" height="535" alt="xampp_activate" src="https://github.com/user-attachments/assets/8ce6e383-3318-46d7-8809-4db60dc1834a" />

Open the XAMPP Control Panel and activate both the Apache and MySQL (or MariaDB) Modules simply by pressing the "Start" button next to each module.

Create a new folder named "MASTER PROJECT - SATAY UNCLE UJANG SYSTEM" inside the "C:\xampp\htdocs" directory.

Clone or copy your repository, Satay_Kajang_Uncle_Ujang_Ordering_System_Group1 (Replace with your actual repository name), into that folder.

Download the database file from the section.

Open phpMyAdmin (via the XAMPP Control Panel, click the "Admin" button next to MySQL/MariaDB) and create a new database named "satay_db" (Or the specific database name you are using).

Import the downloaded database file, e.g., "satay_db.sql", into the newly created "satay_db" database.

To run the website, open a new browser tab and enter the following URL:

"localhost/MASTER PROJECT - SATAY UNCLE UJANG SYSTEM/Satay_Kajang_Uncle_Ujang_Ordering_System_Group1/SYSTEM FOLDER/Codes/index.php" (Adjust this path to your actual folder structure)

When you first enter "index.php", you will be signed in as a guest. Use the credentials provided in to log in as an Admin, Staff, or regular User.

Enjoy!
